# Community support

Sniper Community is maintained on a best-effort basis and has no support SLA. Before requesting help, use the latest
published Community release, read `README.md` and `DEPLOYMENT.md`, and run the documented validation command.

Use a public GitHub issue for reproducible bugs and focused feature requests. Include the Community version or commit,
operating system, relevant local configuration, the smallest safe reproduction, expected behavior, and actual
behavior. Remove credentials, personal data, customer code, production databases, and generated evidence.

Do not disclose a suspected vulnerability in a public issue. Use GitHub Private Vulnerability Reporting as described
in `SECURITY.md`. Security reports follow that policy rather than the public support path.

Support does not include assessing third-party systems without permission. Test external targets only when you own
them or are explicitly authorized, and stay within the written scope, rate limits, data rules, and stop conditions.

Enterprise editions, commercial services, private installers, and contractual support are separate from this
Apache-2.0 Community repository.
